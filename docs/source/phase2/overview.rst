Phase 2 Overview
=================

.. list-table::
   :widths: 30 70
   :stub-columns: 1

   * - **Prerequisite**
     - Phase 1 tag ``v0.1.0`` exists and CI is green on ``main``
   * - **Goal**
     - Extend the library with a 2D Range-Doppler processing pipeline using
       FFTW3, a CA-CFAR detector, and a Python visualisation script.
   * - **Git tag**
     - ``v0.2.0``
   * - **New dependency**
     - FFTW3 (``libfftw3f``)
